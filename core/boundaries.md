# Authorization and data boundaries

Product source and empty templates are publishable. Initialized workspaces are owner-only local data directories. The separate Vault stores authoritative records, raw messages, file bytes and source grants.

Grant only a named manifest or file under a selected source. Confirm the sensitivity level, retention period and intended recipients before ingesting personal data. Raw messages require separate authorization. Cross-agent network transport and publication require an approved destination. Keep credentials in the actual credential provider.

An external reference does not establish local bytes or permission. Check the target at the point of use. Restore and test backups inside access controls equivalent to the source.
