# Memory Bootstrap

1. Obtain the actual workspace path or approved export. Read [AGENTS.md](../AGENTS.md) then [the core index](../core/INDEX.md).
2. Run `workspace check --path WORKSPACE` when the CLI and Vault are available. Compare its `template_version` and `engine_version` with the last read. Reread the relevant instructions when the template changes, and reread actual record revisions after an import or review.
3. Read the current project and authorized session views. Separately confirm exact file versions and access. Use `local status` for grants and sync coverage.
4. Save a durable candidate only after checking source and sensitivity. Have the owner approve it through [memory review](../workflows/memory-lifecycle.md).
5. If direct access is unavailable, ask for the minimal text, normalized envelope, approved manifest or handoff package. Report what was actually read.

Copyable request: “Use the approved workspace entry file first. State the version, scope and missing permissions. Consider only the provided project and evidence. Submit proposed durable changes as candidates for review.”
