# README 多语言维护与验收约定
## 首页定位
根目录 `README.md` 默认简体中文；其余八种语言位于 `docs/i18n/`。README 面向普通用户，以项目功能、资料组织、设计机制和 Agent 自助使用体验为主，不承担完整命令行手册职责。
主 README 的章节依次说明：项目概述、架构、核心能力、Agent 辅助初始化、主要应用场景、隐私与同步机制、实际能力边界、相关文档。中英文保持同一信息层次，其余语言保留对应的导航和必要技术边界。
## 一段指令作为主要入口
首页提供一份无空行、适合复制的 Agent 初始化 Prompt，其中包含准确的通用仓库地址、`AGENTS.md` 与 `docs/agent-onboarding*.md`。读者只需要交给具备实际权限的 Agent，再对必要的账户、资料、远端发布和持续调度作范围明确的授权。
可执行的命令、审批摘要、Git 投影细节、恢复路径和故障排查保存在 [中文部署指南](agent-onboarding.zh-CN.md)、[英文部署指南](agent-onboarding.md)、[工作区说明](workspace.md) 与 [运维手册](guide.md)。不要在 README 重复几十行安装、导入和交接命令。
## 功能陈述与安全边界
V2.4 已实现受审的模块化 Private Git 投影和模拟远端建库/发布，但尚未实测真实 GitHub 账号；资料来源依赖实际授权与可访问的导出/连接。默认不上传完整 Vault、原始 L3、附件或秘密，不自动安装周期调度。
程序保留 Vault 2.1、Workspace 1.0 和离线交接 2.2。文档更新须保留 L0–L3、12/52/134、候选审核、真实文件字节及逐 Agent 版本确认的准确解释。
## 质量检查
`python scripts/check_readme_i18n.py` 检查中文默认首页、九语言导航、专业章节、完整的可复制 Prompt、本地链接和 L0–L3。CI 继续执行 Windows/Ubuntu 回归及 ZIP、Bundle、SHA-256、Git 历史审计。工具没有实际权限时应如实报告，不得将技术设计和模拟测试写成真实环境全面可用。
