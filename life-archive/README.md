# Life archive

[Profile](profile.json) covers the twelve categories described in [taxonomy](taxonomy.md). All categories initially say `unknown`. [Timeline](timeline.json) keeps dated evidence separate from current profile entries. The [schema](../schemas/life-archive.schema.json) defines source type, evidence level, validity, precision, related records and revision lineage.

Read only authorized categories. Keep restricted originals in separately approved storage, and use opaque evidence references here. Use `workspace check` for structural validation and category coverage. The optional [health extension](health/README.md) accepts a deliberately narrow aggregate format.
